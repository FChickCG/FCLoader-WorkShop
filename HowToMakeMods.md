# FCLoader Workshop — как подписать свой мод

Чтобы в мастерской (Workshop) твой мод отображался с **красивым названием** и **твоим ником**, достаточно написать в начале `.lua`-файла две строки-комментария.

## Формат

В **первых 40 строках** файла, в любом месте (обычно в самом верху):

```lua
-- name: Название твоего мода
-- author: Твой ник
```

`name` и `author` — это ключи. После двоеточия пиши значение. Что ещё можно использовать вместо `name`: `title`, `название`. Вместо `author`: `автор`, `by`.

## Пример

```lua
-- name: Монеты (Coins)
-- author: FChick

api.log("мой мод загружен")

api.guiButton("МОНЕТЫ", function()
    api.coinWindow()
end)
```

В мастерской это покажется так:

```
[иконка] Монеты (Coins)      [УСТАНОВИТЬ]
         by FChick
```

## Правила

- Строка обязана начинаться с `--` (это комментарий Lua — сам скрипт его игнорирует).
- Ключ и значение разделяются двоеточием `:`. Пробелы вокруг не важны.
- **Не пиши `name`/`author` в конце файла** — парсер смотрит только начало (первые 40 строк).
- Если `name` нет — покажется имя файла. Если `author` нет — подпись «by …» не появится.
- Одна строка = одно поле. Первое найденное значение выигрывает.
- Кодировка файла — UTF-8, чтобы русские буквы не побились.

## Быстрая проверка

```lua
-- name: Тестовый мод
-- author: ТвойНик
api.log("ok")
```

Загрузи мод, открой вкладку МОДЫ или МАСТЕРСКАЯ — сверху строки будут название и ник. Хочешь поменять — правь строки и перезагружай мод.
